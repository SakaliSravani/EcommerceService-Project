# E-Commerce Service Project

This is a Spring Boot based E-Commerce Service application developed using Java and REST APIs.


## Technologies Used 
- Java
- Spring Boot
- Maven
- REST APIs


## Features 
- Add Products
- View Products
- Update Products
- Product Mnagement APIs


 ## How to Run
 1. Run the Spring Boot application
 2. Open browser or Postman
 3. Use API endpoints to manage products
